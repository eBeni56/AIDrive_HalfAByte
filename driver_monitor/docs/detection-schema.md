# `driver_state` JSON — schema reference (schema_version 1)

The message the driver monitor sends for **every processed camera frame** (~30 per second). This page is the
reference for consumers (simulator, alert manager, voice assistant): every block, every field, every detection
and its `details`. How the values are computed is in [IMPLEMENTATION.md](IMPLEMENTATION.md); 23 complete
examples generated by the real code are in [IMPLEMENTATION.md section 10](IMPLEMENTATION.md#10-examples-generated-by-the-real-code).

* **Source of truth:** the pydantic model [output/schema.py](../src/driver_monitor/output/schema.py).
* **Machine-readable JSON Schema:** [driver_state.schema.json](driver_state.schema.json) (generated from the
  model, kept in sync by a test; regenerate with
  `uv run python -m driver_monitor --print-schema | Out-File -Encoding utf8 docs/driver_state.schema.json`).
* **Emotions are not included.**

## 1. Transport

| Channel | How |
|---|---|
| **WebSocket** (live) | One WebSocket **text message = one complete `driver_state` JSON object**, sent while the camera runs. The monitor is the *client*: it connects to `websocket.url` from [config/driver_monitor.yaml](../config/driver_monitor.yaml) (default `ws://localhost:8765`; `--ws URL` overrides, `--no-ws` disables) and reconnects every 2 s if the server is not there. Nothing is buffered while disconnected (the receiver gets the live state). `websocket.max_rate_hz` can limit the rate (0 = every frame). Test server: `uv run python tools/ws_receiver.py`. |
| **JSON Lines file** | `--json session.jsonl`: every message, one per line. |
| **Terminal** | `j` in the window / `--print-json`: the full JSON once per second. |

A consumer that does not read every message should watch the detection `status` (`STARTED` / `ENDED`) or keep the
latest message per detection `id`: an `ENDED` detection is included **exactly once**.

## 2. The idea: three layers

| Layer | Blocks | Answers | Memory |
|---|---|---|---|
| **1. Signals** | `quality`, `calibration`, `eyes`, `head`, `gaze`, `mouth` | What is measured *right now* (smoothed numbers + a simple state) | current frame |
| **2. Windowed state** | `attention`, `drowsiness` | What has been going on over seconds / minutes (glances, PERCLOS, fatigue history, level) | rolling windows 30 s – 15 min |
| **3. Detections** | `detections[]`, `summary` | Which labelled problems are happening — each with a stable `id`, start time, duration, severity and its own `details` | an episode lives across many frames |

* **Stateful:** eyes closed for 40 frames = **one** `MICROSLEEP` episode whose `duration_s` grows, `status`
  `STARTED → ONGOING → ENDED` — not 40 events.
* **A state is not a detection:** `eyes.state = CLOSED` during a 150 ms blink, or `gaze.zone = LEFT_MIRROR`
  during a mirror check, are measurements. They become detections only when the timing rules say so.

## 3. Conventions

| Thing | Convention |
|---|---|
| `t` | Seconds on a monotonic clock since program start (3 decimals). All durations come from timestamps, never frame counts. |
| Left / right | The **driver's own** left/right (not image left/right). |
| `*yaw_deg` | **Negative = left, positive = right**, 0 = straight ahead (same as the simulator's `bearing_deg`). |
| `*pitch_deg` | **Positive = up, negative = down.** |
| `*roll_deg` | **Negative = toward the left shoulder, positive = toward the right shoulder.** |
| Angles | Relative to the driver's **calibrated straight-ahead pose** (looking at the road / screen centre). |
| `openness` | 0 = this driver's closed eye, **1.0 = this driver's calibrated open eye** (up to 1.3). Normalised per driver, so eye size does not matter. |
| `openness_ratio` | Current openness ÷ this driver's **normal opening while driving** (learned after calibration). < 0.85 for 5 s = narrowed eyes. |
| `null` | Not measurable now (e.g. eye values with the face lost). Never invented. |
| Severity | `INFO` < `WARNING` < `DANGER` < `CRITICAL` (`NONE` only in `summary.highest_severity`). |
| Enums | UPPERCASE strings. |
| Units in names | `_s` seconds, `_ms` milliseconds, `_deg` degrees, `_dps` degrees/second, `_per_min`, `_60s` / `_5min` = window length. |

## 4. Top-level structure

```
driver_state
├─ type: "driver_state", schema_version: 1, t, frame
├─ summary       { highest_severity, primary, active[] }
├─ quality       { fps, camera_fps, latency_ms, face_detected, faces_in_view, face_lost_for_s,
│                  eye_metrics_reliable, issues[] }
├─ calibration   { status, phase, progress, message, neutral_head{yaw_deg,pitch_deg,roll_deg}, open_ear{left,right} }
├─ eyes          { left{openness,ear,blink_score,state}, right{…}, openness, state, state_for_s, trend,
│                  openness_velocity_per_s, source, lid_lowered_by_gaze, last_blink{ended_t,duration_ms},
│                  normal_openness, normal_learned, openness_ratio }
├─ head          { yaw_deg, pitch_deg, roll_deg, yaw_velocity_dps, pitch_velocity_dps, roll_velocity_dps }
├─ gaze          { direction, horizontal, vertical, intensity, yaw_deg, pitch_deg, head_yaw_deg, head_pitch_deg,
│                  eye_yaw_deg, eye_pitch_deg, on_road, direction_for_s, zone, zone_for_s }
├─ mouth         { jaw_open, mar, state, state_for_s }
├─ attention     { state, zone, eyes_off_road_s, glance_down_s, off_road_last_30s_s, weighted_off_road_30s_s,
│                  longest_glance_60s_s, glances_60s }
├─ drowsiness    { level, level_index, score, peak_level, warming_up, contributing[], fatigue_load,
│                  history[ {window_s, long_eye_closures, microsleeps, closed_eyes_s, yawns, head_nods,
│                            head_falls, narrowed_eyes, narrowed_eyes_s} ],
│                  indicators{ perclos, perclos_window_s, blink_rate_per_min, mean_blink_duration_ms,
│                              long_blinks_60s, mean_openness_60s, mean_openness_ratio_60s, yawns_5min,
│                              head_nods_5min, head_falls_10min, microsleeps_10min } }
└─ detections[]  { id, type, severity, status, started_t, ended_t, duration_s, details{…type-specific…} }
```

## 5. Field reference

**Header** — `type` always `"driver_state"`, `schema_version` `1`, `t` (s), `frame` (counter since start).

**`summary`**

| Field | Type | Meaning |
|---|---|---|
| `highest_severity` | enum | Highest severity among active (not `ENDED`) detections, or `NONE`. |
| `primary` | string \| null | Type of the most severe active detection (tie → most recent). |
| `active` | string[] | Types of all active detections. |

**`quality`**

| Field | Type | Meaning |
|---|---|---|
| `fps` | float | Frames processed per second. |
| `camera_fps` | float \| null | Frames the camera really delivers (`null` for video files). |
| `latency_ms` | float | Processing time of this frame. |
| `face_detected` | bool | A face was found in this frame. |
| `faces_in_view` | int | Faces seen (the largest/closest one is the driver). |
| `face_lost_for_s` | float | 0 while visible, else seconds since the face was last seen. |
| `eye_metrics_reliable` | bool | False when the head is turned/pitched too far (\|yaw\| > 40°, pitch < −35° or > 30°), the face is too small or partly out of the frame. Eye detections are **suspended, not triggered**, while false. |
| `issues` | enum[] | `CALIBRATING`, `HEAD_TURNED_TOO_FAR`, `FACE_TOO_SMALL`, `FACE_PARTIALLY_OUT_OF_FRAME`, `LOW_LIGHT` (mean gray < 50), `LOW_FPS` (< 15). |

**`calibration`**

| Field | Type | Meaning |
|---|---|---|
| `status` | enum | `CALIBRATING` (first ~10 s) \| `DONE` \| `DEFAULTS` (skipped → population defaults, less accurate). |
| `phase` | enum \| null | `OPEN_EYES` (look straight ahead) \| `CLOSED_EYES` (close your eyes) while calibrating. |
| `progress` | float | 0..1. |
| `message` | string \| null | Instruction while calibrating; notes afterwards (e.g. "closed blink score too close to open - using default"). |
| `neutral_head` | object \| null | Raw camera-relative head angles that count as straight ahead. |
| `open_ear` | object \| null | This driver's open-eye EAR per eye. |

**`eyes`**

| Field | Type | Meaning |
|---|---|---|
| `left` / `right` | object \| null | Per eye: `openness`, `ear` (raw Eye Aspect Ratio), `blink_score` (raw `eyeBlink*` blendshape 0..1), `state`. |
| `openness` | float \| null | Combined openness of the used eye(s), see `source`. |
| `state` | enum | `OPEN` \| `ALMOST_CLOSED` (< 0.55) \| `CLOSED` (< 0.25; with the head down < 0.15) \| `UNKNOWN`. With hysteresis. |
| `state_for_s` | float | How long the current state has lasted. |
| `trend` | enum | `CLOSING` \| `OPENING` \| `STABLE`. |
| `openness_velocity_per_s` | float | Smoothed d(openness)/dt. |
| `source` | enum | `BOTH` \| `LEFT_ONLY` \| `RIGHT_ONLY` (head turned > 20°: only the eye facing the camera). |
| `lid_lowered_by_gaze` | bool | Head pitched down with not-closed but narrowed eyes: the lids follow the look down (not droopiness). |
| `last_blink` | object \| null | `{ ended_t, duration_ms }` of the last completed blink. |
| `normal_openness` | float | This driver's normal opening while driving (learned from the first ~30 s of clean samples after calibration; 1.0 until then). |
| `normal_learned` | bool | True once `normal_openness` is learned (narrowed-eye detection works only then). |
| `openness_ratio` | float \| null | 3 s median openness (blinks, looking down, smiling, yawning excluded) ÷ `normal_openness`. `null` without enough clean samples. |

**`head`** — `yaw_deg`, `pitch_deg`, `roll_deg` relative to neutral (smoothed) and their velocities `*_velocity_dps`. `null` without a face.

**`gaze`**

| Field | Type | Meaning |
|---|---|---|
| `direction` | enum | `CENTER`, `LEFT`, `RIGHT`, `UP`, `DOWN`, `UP_LEFT`, `UP_RIGHT`, `DOWN_LEFT`, `DOWN_RIGHT`, `UNKNOWN` (eyes closed > 0.5 s / face lost). |
| `horizontal` / `vertical` | enum | `LEFT`/`CENTER`/`RIGHT` (beyond ±12°) and `UP`/`CENTER`/`DOWN` (beyond +12° / −10°). |
| `intensity` | enum | `NONE` < 12° ≤ `SLIGHT` < 25° ≤ `MODERATE` < 45° ≤ `STRONG` < 65° ≤ `EXTREME` (larger of \|yaw\|, \|pitch\|). |
| `yaw_deg` / `pitch_deg` | float \| null | **Combined gaze = head angle + eye-in-head angle.** The numbers to match against objects / screen regions. |
| `head_yaw_deg` / `head_pitch_deg` | float \| null | Head part (more accurate, ±3–5°). |
| `eye_yaw_deg` / `eye_pitch_deg` | float \| null | Eye-in-head part (rougher, ±5–10°); `null` when the eyes are unreliable → head-only gaze. |
| `on_road` | bool \| null | Inside the road box (\|yaw\| ≤ 20°, −15° ≤ pitch ≤ 15°). |
| `direction_for_s` | float | How long the current `direction` has lasted. |
| `zone` | enum | Where the driver looks: `ROAD`, `REAR_MIRROR`, `LEFT_MIRROR`, `RIGHT_MIRROR`, `LEFT_SIDE`, `RIGHT_SIDE`, `UP`, `DOWN`, `UNKNOWN`. Mirror boxes from the `gaze_zones` config (default: simulator screen — rear-view mirror top centre, side mirrors in the lower corners); below the road box = `DOWN`. |
| `zone_for_s` | float | How long the current zone has lasted. |

Default mirror boxes (`gaze_zones`, combined gaze angles; checked before the road box):

| Zone | yaw | pitch |
|---|---|---|
| `REAR_MIRROR` | −12° … 12° | 8° … 25° |
| `LEFT_MIRROR` | −38° … −12° | −25° … −3° |
| `RIGHT_MIRROR` | 12° … 38° | −25° … −3° |

**`mouth`** — `jaw_open` (blendshape 0..1), `mar` (inner-lip Mouth Aspect Ratio), `state` `CLOSED` \| `OPEN` \| `WIDE_OPEN` \| `UNKNOWN`, `state_for_s`.

**`attention`**

| Field | Type | Meaning |
|---|---|---|
| `state` | enum | `ATTENTIVE` (road) \| `CHECKING_MIRROR` \| `GLANCING_AWAY` (off-road, within the limits) \| `DISTRACTED` (a `DISTRACTED` detection is active) \| `UNKNOWN` (eyes closed / face lost — handled by the drowsiness and face detections, never counted as distraction). |
| `zone` | enum | Current gaze zone (as `gaze.zone`). |
| `eyes_off_road_s` | float | Current glance away from the road (mirrors included), 0 on the road. |
| `glance_down_s` | float | Part of the current glance spent looking `DOWN`. |
| `off_road_last_30s_s` | float | Off-road time in the last 30 s. |
| `weighted_off_road_30s_s` | float | Same, weighted: down ×1, sideways/up ×0.5, mirrors ×0 (the `CUMULATIVE` rule). |
| `longest_glance_60s_s` | float | Longest glance in the last 60 s (incl. the current one). |
| `glances_60s` | int | Glances ≥ 0.2 s in the last 60 s. |

**`drowsiness`**

| Field | Type | Meaning |
|---|---|---|
| `level` | enum | `ALERT` \| `SLIGHTLY_DROWSY` \| `DROWSY` \| `VERY_DROWSY` \| `SEVERELY_DROWSY`. Builds up from evidence over seconds–minutes and **recovers** (at most one step per 30 s) when the evidence fades. |
| `level_index` | int | 0–4. |
| `score` | float | 0..1 smoothed evidence score (level thresholds 0.25 / 0.45 / 0.65 / 0.80). |
| `peak_level` | enum | Highest level this session. Once it reached `VERY_DROWSY`, the level never drops below peak − 2 (fatigue memory). |
| `warming_up` | bool | True until ≥ 30 s of eye data (60 s statistics not ready). |
| `contributing` | enum[] | Why, strongest first: `HIGH_PERCLOS`, `HEAVY_EYELIDS`, `SLOW_BLINKS`, `FREQUENT_LONG_BLINKS`, `NARROWED_EYES`, and the event kinds of the fatigue load: `MICROSLEEPS`, `LONG_EYE_CLOSURES`, `HEAD_NODS`, `HEAD_FALLING`, `YAWNING`. |
| `fatigue_load` | float | Decaying sum of past fatigue events (half-life 5 min). Eye closure ≥ 0.5 s weighted by its duration (0.5 s → 0.2, 1 s → 0.5, 2 s → 1.1, 3 s → 1.5, 5 s → 2.0), head fall 1.0, nod 0.6, yawn 0.4, narrowed-eye episode 0.5 per minute (max 1.0). One long closure weighs a lot at once and fades; many shorter ones stack up. |
| `history` | object[] | Per window (`window_s` 60 / 300 / 900): `long_eye_closures` (≥ 0.5 s, incl. microsleeps), `microsleeps`, `closed_eyes_s`, `yawns`, `head_nods`, `head_falls`, `narrowed_eyes` (episodes), `narrowed_eyes_s`. |
| `indicators` | object | See below. |

`drowsiness.indicators`:

| Field | Meaning |
|---|---|
| `perclos` | Fraction of the last 60 s with eyes ≥ 80 % closed (openness ≤ 0.2); only reliable eye data counts. `null` while warming up. |
| `perclos_window_s` | Valid data in the 60 s window. |
| `blink_rate_per_min` | Blinks per minute (after 20 s). |
| `mean_blink_duration_ms` | Mean blink duration in the last 60 s. |
| `long_blinks_60s` | Closures of 0.5–1 s in the last 60 s. |
| `mean_openness_60s` | Mean openness of not-closed eyes (60 s). |
| `mean_openness_ratio_60s` | The same ÷ the driver's normal opening (heavy eyelids < 0.8). |
| `yawns_5min`, `head_nods_5min`, `head_falls_10min`, `microsleeps_10min` | Counts in those windows. |

**`detections[]`** — common header of every detection:

| Field | Type | Meaning |
|---|---|---|
| `id` | string | Stable episode id, e.g. `"microsleep-3"` — the same in every message of the episode. |
| `type` | enum | See section 6. |
| `severity` | enum | Can **rise** during an episode (e.g. `DISTRACTED` WARNING → DANGER); only `DROWSY` can also go down. |
| `status` | enum | `STARTED` (first message) \| `ONGOING` \| `ENDED` (sent exactly once). |
| `started_t` | float | When the underlying condition began (e.g. when the eyes closed — not when the threshold was crossed). |
| `ended_t` | float \| null | Set when `ENDED`. |
| `duration_s` | float | `t − started_t` (or `ended_t − started_t`). |
| `details` | object | Type-specific, see section 6.2. |

`detections` are sorted active first, most severe first.

## 6. Detections

### 6.1 Catalogue

All numbers are defaults from [config.py](../src/driver_monitor/config.py) (overridable in the YAML settings).

| Type | Means | Starts when | Severity | Ends when |
|---|---|---|---|---|
| `EYES_CLOSED` | Eyes shut longer than a blink | `CLOSED` ≥ 0.5 s | WARNING | eyes reopen (`outcome: REOPENED`) or it becomes a microsleep (`ESCALATED_TO_MICROSLEEP`) |
| `MICROSLEEP` | Eyes shut dangerously long — **instant alarm** | `CLOSED` ≥ 1.0 s (same `started_t` as `EYES_CLOSED`) | CRITICAL | eyes not closed for 0.3 s (`REOPENED`), or tracking lost > 2 s (`TRACKING_LOST`) |
| `EYES_ALMOST_CLOSED` | Eyes held nearly shut | `ALMOST_CLOSED` ≥ 2 s, not looking down / smiling / yawning | WARNING | 1 s without it |
| `EYES_NARROWED` | Eyes open but clearly narrower than **this driver's normal** (early tiredness) | `openness_ratio` < 0.85 for 5 s (only after the normal opening is learned) | INFO; WARNING if < 0.7 or ≥ 20 s | ratio > 0.9 for 2 s |
| `TIRED_EYES` | Heavy-eyed pattern over the last minute | 60 s window: `HEAVY_EYELIDS` (mean ratio < 0.8), `SLOW_BLINKS` (> 300 ms), `FREQUENT_LONG_BLINKS` (≥ 3) | INFO; WARNING with 2+ reasons | 30 s without any reason |
| `YAWN` | A yawn | one continuous mouth opening: wide (MAR ≥ 0.55 or jaw ≥ 0.65) ≥ 0.4 s, or moderate (MAR ≥ 0.40 or jaw ≥ 0.50) ≥ 1.5 s | INFO | mouth below the open level for 0.5 s |
| `HEAD_NOD` | Quick drowsy head drop + catch | pitch drop ≥ 12° at ≥ 25°/s from a normal position, recovers within 2 s, eyes **measured closed** ≥ 0.4 s during it | WARNING; DANGER if closed ≥ 0.5 s | reported once, as `ENDED` |
| `HEAD_FALLING` | Head sinking / slumping / tipping back **with closed eyes** | held down ≥ 15° (or \|roll\| ≥ 20°, back ≥ 20°) with closed eyes ≥ 1 s, steady drift with closed eyes, or a sudden drop; never with open eyes or the head turned > 30° | DANGER; CRITICAL with closed eyes / microsleep or ≥ 30° | head back within 8° for 1 s (`RECOVERED`), eyes open 2 s (`EYES_REOPENED`), or `FACE_LOST` |
| `DISTRACTED` | Eyes open but away from the road too long | `LOOKING_DOWN`: ≥ 1.2 s down in one glance · `LONG_GLANCE`: one glance ≥ 3 s (sideways, up, staring at a mirror) · `CUMULATIVE`: weighted off-road ≥ 10 s in 30 s | WARNING; DANGER at 2 s down / 5 s glance | back on the road 1 s and weighted cumulative < 8 s |
| `FACE_NOT_VISIBLE` | The driver cannot be seen (fail-safe) | no face ≥ 2 s | WARNING; DANGER ≥ 5 s or `HEAD_DROPPED` | face back for 0.5 s |
| `DROWSY` | Overall tiredness level | `drowsiness.level` ≥ `SLIGHTLY_DROWSY` | level 1 INFO, 2 WARNING, 3 DANGER, 4 CRITICAL (follows the level, also down) | level back at `ALERT` |

**Tired vs. not paying attention.** `EYES_CLOSED`, `MICROSLEEP`, `EYES_ALMOST_CLOSED`, `EYES_NARROWED`,
`TIRED_EYES`, `YAWN`, `HEAD_NOD`, `HEAD_FALLING`, `DROWSY` = the body is shutting down. `DISTRACTED` = the eyes
work but point away from the road. Closed eyes are **never** distraction (gaze `UNKNOWN`). Looking **down** has no
excuse while driving (1.2 s), looking sideways often has (3 s), mirror checks are part of driving.

**Speed.** How dangerous a closure is depends on the speed (2 s at 130 km/h = 72 m blind); the consumer that knows
the speed decides. It gets every `MICROSLEEP` instantly with its exact `closed_for_s`.

### 7.1 Normal, attentive driving (complete message)

```json
{
  "type": "driver_state",
  "schema_version": 1,
  "t": 63.9,
  "frame": 1918,
  "summary": {"highest_severity": "NONE", "primary": null, "active": []},
  "quality": {
    "fps": 30.0, "camera_fps": null, "latency_ms": 12.0, "face_detected": true, "faces_in_view": 1,
    "face_lost_for_s": 0.0, "eye_metrics_reliable": true, "issues": []
  },
  "calibration": {
    "status": "DEFAULTS", "phase": null, "progress": 1.0,
    "message": "population defaults - run calibration for accurate results",
    "neutral_head": {"yaw_deg": 0.0, "pitch_deg": 0.0, "roll_deg": 0.0},
    "open_ear": {"left": 0.28, "right": 0.28}
  },
```

### Changes since the first draft (pre-implementation)

* Added: `quality.camera_fps`, `quality.faces_in_view`; `calibration.phase` / `message`; `eyes.normal_openness` /
  `normal_learned` / `openness_ratio`; `gaze.zone` / `zone_for_s`; `attention.zone`, `glance_down_s`,
  `weighted_off_road_30s_s`, state `CHECKING_MIRROR`; `drowsiness.fatigue_load`, `drowsiness.history`,
  `indicators.mean_openness_ratio_60s`; detection type `EYES_NARROWED`; `DISTRACTED` reasons `LOOKING_DOWN`
  (1.2 s) and per-zone limits (sideways 3 s); `HEAD_FALLING` details `start_value_deg` / `change_deg` / `trend`
  (pitch and roll) and `outcome`.
* Removed: `quality.face_confidence` (the Python MediaPipe API has no presence score).
* Changed: no hard drowsiness floors — the level recovers (one step per 30 s) and fatigue memory applies only after
  `VERY_DROWSY`; `HEAD_FALLING` and `HEAD_NOD` require measured closed eyes; yawn = one continuous opening (wide
  ≥ 0.4 s or moderate ≥ 1.5 s); `HEAD_NOD` is reported once as `ENDED`.
